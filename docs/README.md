# Documentation

Tracked project documentation belongs in this directory. The wire-protocol
reference is in [protocol.md](protocol.md), while the security policy remains at
the repository root so GitHub can discover it as [SECURITY.md](../SECURITY.md).

Personal learning notes, implementation plans, trackers, and TODO documents
belong in `docs/learning/`. That directory is intentionally ignored by Git so
private study material does not become part of commits or pull requests.
